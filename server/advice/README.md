# «Мнение Лиса» от YandexGPT — настройка

Схема: **приложение → облачная функция (посредник) → YandexGPT**. Ключей в приложении нет:
функция ходит в YandexGPT от имени своего сервисного аккаунта.

Физиологию считает само приложение (движок `src/domain/physiology.ts`): сравнивает ночь, вчерашний
день, последние часы и последний час с вашими нормами и находит одну главную связку. Наружу уходят
только две фразы без цифр — что с телом сейчас (`consequence`) и почему (`root_cause`) — и тексты
прошлых мнений Лиса (их функция использует только для проверки на повтор, модели не отдаёт).
Ни имени, ни пола, возраста, роста, веса, ни чисел с кольца в запросе нет.

Модель получает только эти две фразы и пересказывает их голосом Лиса: два коротких предложения до
130 символов. Функция проверяет ответ: без цифр, команд, выдуманных «дел» и «работы», шаблонных
«Возможно/Вероятно», зауми и повторов. Не прошёл — один повтор с причиной; не вышло — показывается
шаблонный совет.

## 1. Аккаунт и оплата (один раз)

1. Откройте https://console.yandex.cloud и войдите через Яндекс ID.
2. Создайте **платёжный аккаунт**: «Биллинг» → «Создать аккаунт» → физическое лицо → привяжите карту.
   Новым пользователям обычно дают стартовый грант — условия видны на странице биллинга.
3. Сразу заведите **бюджет**, чтобы не было сюрпризов: «Биллинг» → «Бюджеты» → «Создать бюджет»,
   например 300 ₽ в месяц с уведомлением на почту.
4. В облаке уже есть каталог `default` — можно работать в нём. Скопируйте его **идентификатор**
   (строка вида `b1g…`, видна на странице каталога): это `FOLDER_ID`.

## 2. Сервисный аккаунт

1. В каталоге: «Сервисные аккаунты» (или «Identity and Access Management» → «Сервисные аккаунты») → «Создать».
2. Имя: `vuelo-advice`. Роль: **`ai.languageModels.user`**. Создать.
   API-ключ создавать не нужно.

## 3. Облачная функция

1. «Все сервисы» → **Cloud Functions** → «Создать функцию», имя `vuelo-advice`.
2. Вкладка «Редактор»: среда выполнения **Node.js 22**, «Редактор кода» → создайте файл `index.js`
   и вставьте в него содержимое файла `server/advice/index.js` из проекта.
3. Параметры версии:
   - точка входа: `index.handler`;
   - таймаут: `15` секунд, память: `128 МБ`;
   - сервисный аккаунт: `vuelo-advice`;
   - переменные окружения:
     - `FOLDER_ID` — идентификатор каталога из шага 1;
     - `APP_KEY` — длинная случайная строка. Получить в терминале Mac: `openssl rand -hex 24`;
     - `MODEL` — можно не задавать (по умолчанию `yandexgpt` — YandexGPT Pro).
       Дешевле — `yandexgpt-lite`, новее — `aliceai-llm`. Меняется без правки кода.
4. «Сохранить изменения». На вкладке «Обзор» включите **«Публичная функция»**
   и скопируйте **ссылку для вызова** (`https://functions.yandexcloud.net/d4e…`).

### Обновить код функции (после правок в проекте)

1. В терминале Mac, из папки проекта, скопируйте файл в буфер обмена одной командой:
   ```
   pbcopy < server/advice/index.js
   ```
2. Yandex Cloud → Cloud Functions → `vuelo-advice` → «Редактор» → файл `index.js`: выделите всё
   (`Cmd+A`), вставьте (`Cmd+V`) → «Сохранить изменения». Переменные окружения и настройки не трогайте.
3. Новая версия работает сразу; пересобирать приложение ради этого не нужно.

## 4. Проверка из терминала

Из папки проекта, подставив свою ссылку и ключ (пример запроса — в `server/advice/sample.json`):

```
curl -X POST 'https://functions.yandexcloud.net/ВАШ_ID' \
  -H 'Content-Type: application/json' \
  -H 'X-Vuelo-Key: ВАШ_APP_KEY' \
  --data-binary @server/advice/sample.json
```

Ответ `{"text":"…","mode":"free","v":6}` — всё работает: `text` — то, что увидит человек,
`v` — версия кода функции (нет `v` или меньше 9 — в Yandex Cloud старый код, «Сырой лог» об этом скажет).

Запустите команду 2–3 раза: смысл тот же (факт и причина из `insight`), слова разные. Поменяйте в
`sample.json` фразы `consequence` и `root_cause` — ответ перескажет уже их.

`403` — не совпал ключ; `400` — в функции старый код (вставьте `index.js` заново);
`502` с `llm …` — у сервисного аккаунта нет роли или неверный `FOLDER_ID` (подробности — во вкладке
«Логи» функции); `502` с `answer …` — два ответа подряд не прошли проверку (`sentences` — не два
предложения, `long` — длиннее 130 символов, `numbers` — цифры, `command` — совет или команда,
`hedge` — «Возможно/Вероятно» в начале, `invented` — выдуманные дела или работа, `tautology` — второе
предложение повторяет первое, `horoscope` — «вы устали» и т. п., `touchy`, `breathing`, `esoteric`,
`jargon` — заумь, `day_sleep` — днём зовёт поспать, `forbidden` — медицина, глюкоза, давление или
бренды, `repeat` — повтор прежнего мнения): приложение покажет шаблон. `400` с `insight` — в приложении
старая сборка: пересоберите её.
Если `502` бывает часто — поставьте `MODEL=yandexgpt` (Pro): Lite хуже держит формат.

## 5. Приложение

```
cd ~/путь/к/project
cp .env.example .env
open -e .env
```

Впишите ссылку в `EXPO_PUBLIC_ADVICE_URL` и тот же ключ в `EXPO_PUBLIC_ADVICE_KEY`, сохраните.
Значения попадают в приложение при сборке, поэтому соберите заново:

```
npx expo run:ios --device --configuration Release
```

Проверка: после обновления данных «Мнение Лиса» на «Сегодня» сменится на текст от модели.
В «Сыром логе» (меню разработчика) — строка «мнение Лиса (после пробуждения) от модели получено»
или причина, почему нет.

Лис говорит трижды за день — по вашему ритму, а не по часам:
- **после пробуждения** — первые 4 часа после подъёма: про ночь и день впереди;
- **днём** — между утром и вечером: как идёт день;
- **перед сном** — последние 3 часа до окна «Режима сна»: про прошедший день и сон.

Новое мнение просится, когда вы открываете приложение в новом отрезке (или приложение открыто
в момент смены отрезка). Пока приложение забирает данные с кольца и ждёт ответ модели, на карточке
«Лис смотрит, как прошла ночь…» с бегущими точками; потом мнение плавно появляется. В фоне iOS
запросов не делает. Не удалось — следующая попытка на тот же отрезок не раньше чем через 30 минут.

Лис не повторяется: приложение помнит, о какой связке он уже говорил, и в следующий раз выбирает
другую, а функция отклоняет ответ, слишком похожий на прошлые мнения.

## Сколько стоит

Один совет — примерно 2 000–2 500 токенов (правила + ряды за неделю + ответ; оценка, точно видно
в «Биллинге»); если понадобился повтор — примерно вдвое больше. Совет просится не больше трёх раз
за день (плюс кнопка «Новое мнение Лиса» в «Сыром логе») и только когда день посчитан. По ценам
AI Studio на июль 2026: YandexGPT Pro — 0.80 ₽ за 1000 токенов (≈ 2 ₽ за совет), Lite — 0.20 ₽ (≈ 0.5 ₽).
Вызовы самой функции на таких объёмах укладываются в бесплатный объём Cloud Functions.
