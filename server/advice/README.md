# «Мнение Лиса» от YandexGPT — настройка

Схема: **приложение → облачная функция (посредник) → YandexGPT**. Ключей в приложении нет:
функция ходит в YandexGPT от имени своего сервисного аккаунта. Приложение отправляет всё о дне,
кроме имени: пол, возраст, рост, вес, цель, сон и пульс во сне, шаги и калории, замеры «Организма»
(без значений глюкозы и давления) — таблицей чисел по дням за неделю, и план Vuelo на сегодня
(тренировка, кофе, еда, время сна).

Как у Oura Advisor, ИИ анализирует не сырые замеры, а то, что уже посчитано: функция сравнивает
каждый показатель с обычным для человека за неделю и передаёт модели всё, что заметно отличается
(«вчера последний приём пищи в 22:30 — обычно около 19:42», «засыпание три ночи подряд всё позже»…),
и действия из плана Vuelo. Что главное, что с чем связано, какая причина и что посоветовать — решает
модель; Лис говорит это двумя предложениями, без чисел и названий показателей. Если ответ модели
невпопад (например, «легли поздно — поешьте по графику»), функция делает запасной шаг: главное
выбирает правило, модель только пересказывает. Не настроено или не ответило — показывается
шаблонный совет, как раньше.

## 1. Аккаунт и оплата (один раз)

1. Откройте https://console.yandex.cloud и войдите через Яндекс ID.
2. Создайте **платёжный аккаунт**: «Биллинг» → «Создать аккаунт» → физическое лицо → привяжите карту.
   Новым пользователям обычно дают стартовый грант — условия видны на странице биллинга.
3. Сразу заведите **бюджет**, чтобы не было сюрпризов: «Биллинг» → «Бюджеты» → «Создать бюджет»,
   например 300 ₽ в месяц с уведомлением на почту.
4. В облаке уже есть каталог `default` — можно работать в нём. Скопируйте его **идентификатор**
   (строка вида `b1g…`, видна на странице каталога): это `FOLDER_ID`.

## 2. Сервисный аккаунт

1. В каталоге: «Сервисные аккаунты» (или «Identity and Access Management» → «Сервисные аккаунты») → «Создать».
2. Имя: `vuelo-advice`. Роль: **`ai.languageModels.user`**. Создать.
   API-ключ создавать не нужно.

## 3. Облачная функция

1. «Все сервисы» → **Cloud Functions** → «Создать функцию», имя `vuelo-advice`.
2. Вкладка «Редактор»: среда выполнения **Node.js 22**, «Редактор кода» → создайте файл `index.js`
   и вставьте в него содержимое файла `server/advice/index.js` из проекта.
3. Параметры версии:
   - точка входа: `index.handler`;
   - таймаут: `15` секунд, память: `128 МБ`;
   - сервисный аккаунт: `vuelo-advice`;
   - переменные окружения:
     - `FOLDER_ID` — идентификатор каталога из шага 1;
     - `APP_KEY` — длинная случайная строка. Получить в терминале Mac: `openssl rand -hex 24`;
     - `MODEL` — можно не задавать (по умолчанию `yandexgpt` — YandexGPT Pro).
       Дешевле — `yandexgpt-lite`, новее — `aliceai-llm`. Меняется без правки кода.
4. «Сохранить изменения». На вкладке «Обзор» включите **«Публичная функция»**
   и скопируйте **ссылку для вызова** (`https://functions.yandexcloud.net/d4e…`).

## 4. Проверка из терминала

Из папки проекта, подставив свою ссылку и ключ (пример дня — в `server/advice/sample.json`):

```
curl -X POST 'https://functions.yandexcloud.net/ВАШ_ID' \
  -H 'Content-Type: application/json' \
  -H 'X-Vuelo-Key: ВАШ_APP_KEY' \
  --data-binary @server/advice/sample.json
```

Ответ `{"text":"…","mode":"…","focus":[…],"cause":"…"}` — всё работает:
- `text` — то, что увидит человек;
- `mode` — `analysis`: главное и совет выбрал сам ИИ; `guided`: ответ ИИ не прошёл проверку,
  сработал запасной шаг;
- `focus` — что модель сочла главным, `cause` — какую причину назвала.

Метки в `focus`: `late-meal` поздняя еда, `many-meals` много приёмов пищи, `bed-late` / `bed-drift` /
`bed-irregular` позднее / всё более позднее / скачущее засыпание, `sleep-short` / `sleep-long` короткий /
долгий сон, `sleep-debt` долг сна, `deep-low` / `deep-high` глубокий сон, `night-pulse-up` /
`night-pulse-down` пульс во сне, `hrv-down` / `hrv-up` вариабельность, `stress-days` / `stress-up`
стресс, `workout-yesterday` вчерашняя тренировка, `steps-low` / `steps-done` шаги.

Примеры разных дней — подставьте файл в конце команды вместо `sample.json`:
- `sample.json` — сразу несколько поводов: поздний ужин, засыпание всё позже, тяжёлая ночь, три дня
  напряжения. Посмотрите, какую историю выберет модель;
- `sample-wine.json` — спокойный день без поздней еды и тренировки, а ночь тяжёлая и поздняя
  (ждём историю в духе «похоже, вчера был бокал-другой»);
- `sample-work.json` — вчера напряжённый день и поздний отбой («засиделись с работой допоздна»);
- `sample-good.json` — утро после отличной ночи («тело восстановилось — сегодня можно интервалы»).

Одни и те же данные дают похожую историю — это нормально: в приложении данные каждый день свои.
Запустите каждую команду 2–3 раза: слова будут меняться.

`403` — не совпал ключ; `400` — в функции старый код (вставьте `index.js` заново);
`502` с `llm …` — у сервисного аккаунта нет роли или неверный `FOLDER_ID` (подробности — во вкладке
«Логи» функции); `502` с `answer …` — и анализ, и запасной шаг не прошли проверку (`mismatch` — действие не к тому,
`focus` — выдуманная метка, `vague` — расплывчато, `numbers` — лишние числа, `no-time` — без времени
действия, `long` — длинно): приложение покажет шаблонный совет. Если `guided` и `502` бывают часто —
попробуйте `MODEL=yandexgpt` (Pro): анализ требует рассуждать, Pro справляется заметно лучше Lite.

## 5. Приложение

```
cd ~/путь/к/project
cp .env.example .env
open -e .env
```

Впишите ссылку в `EXPO_PUBLIC_ADVICE_URL` и тот же ключ в `EXPO_PUBLIC_ADVICE_KEY`, сохраните.
Значения попадают в приложение при сборке, поэтому соберите заново:

```
npx expo run:ios --device --configuration Release
```

Проверка: после обновления данных «Мнение Лиса» на «Сегодня» сменится на текст от модели.
В «Сыром логе» (меню разработчика) — строка «мнение Лиса (после пробуждения) от модели получено»
или причина, почему нет.

Лис говорит трижды за день — по вашему ритму, а не по часам:
- **после пробуждения** — первые 4 часа после подъёма: про ночь и день впереди;
- **днём** — между утром и вечером: как идёт день;
- **перед сном** — последние 3 часа до окна «Режима сна»: про прошедший день и сон.

Новое мнение просится, когда вы открываете приложение в новом отрезке (или приложение открыто
в момент смены отрезка). В фоне iOS запросов не делает. Не удалось — следующая попытка на тот же
отрезок не раньше чем через 30 минут.

## Сколько стоит

Один совет — около 1 100 токенов (правила + что заметил Vuelo + ответ); если понадобился запасной
шаг — примерно вдвое больше. Совет просится не больше трёх раз за день (после пробуждения, днём,
перед сном) и только когда день посчитан. По ценам AI Studio на июль 2026: YandexGPT Pro — 0.80 ₽ за 1000 токенов
(≈ 0.9 ₽ за совет), Lite — 0.20 ₽ (≈ 0.22 ₽).
Вызовы самой функции на таких объёмах укладываются в бесплатный объём Cloud Functions.
